Thứ tự chạy chạy lần lượt từ trên xuống

1

Save file trước

Tool delete bớt object trong scene. Có undo, nhưng nên giữ một bản save riêng.

2

Set output folder

Bấm ... ở group Output. Mọi file dilation và file AO đều lưu vào đây. Để trống thì tới lúc bake tool mới hỏi. Right-click nút đó để mở folder.

3

Render Dilation group Render Dilation

Render map theo Material ID để lấy phần dilation. Tất cả các nút đều chạy trên object đang select trong viewport.

Size

Resolution file render, từ 512 tới 8192.

Solid / Wire

Màu fill và màu wire của từng Material ID.

CarPaint Details

Lọc material tên carpaint, render ở map channel 1.

Details

Render phần còn lại, trừ danh sách material loại trừ. Object có chữ wheel (không tính steering_wheel, caliper, emissive) được tách thành pass Rim riêng.

Glass · LOD

Lọc theo material tên glass và LOD, map channel 1.

Channel 2

CarPaint và Details_NM làm y hệt nhưng đọc map channel 2.

For lazy people

Chạy liền cả 6 pass trên, khỏi bấm từng nút.

4

AO Setup group Setup - Render AO

Tool tự clean-up scene: switch renderer sang Arnold, collapse modifier stack, delete object trong layer exceptions và LOD2, LOD3, LOD5, delete face tires, underneath, licenseplate.

Sau đó detach cho khỏi dính nhau: carpaint sang phải, glass sang trái, grid xuống dưới. Wheel FL được xoay dựng lên và xếp thành hàng. Hood, door, trunk, wing mở ra.

Kết quả còn 3 object: CARPAINT_attribute_blue, DETAILS_attribute_blue, LOD4, kèm một ground plane để hứng occlusion.

Tool hỏi: caliper trước và sau có khác nhau không? Yes là giữ luôn caliper BL phía sau, No chỉ giữ bộ FL phía trước.
5

Bake AO

Bấm lần lượt 3 nút theo tên object. Mỗi nút tự assign Standard material, set thông số map rồi bake luôn, không cần thao tác gì trong cửa sổ Bake to Texture.

Tool hỏi: có test render không? Yes hạ resolution và samples xuống cho nhanh, No là bake full. Bake xong tool báo đường dẫn file PNG.
CARPAINT
DETAILS
LOD4

Bake AO cho đúng object cùng tên đã attach ở bước 3.

Custom Bake

Làm y hệt nhưng cho object đang select, dùng khi object không đúng tên chuẩn. Select từ 2 object trở lên là tool báo lỗi.

6

Sang Substance group Set for Paint & Check

Dựng lại scene để check rồi hand-off sang Substance Painter.

Setup export
Substance & Check

Detach, move, rotate và open part lần nữa. Tool hỏi Open the part? trước; chọn No thì grid giữ nguyên và bỏ qua bước mở hood, door, trunk, wing.

Add PBR Material

Tạo material PBR Metal/Rough riêng cho CARPAINT và DETAILS. Nút ... bên cạnh trỏ tới folder texture, tool tự tìm và gán 5 map theo tên file.

HDRI Reflections

Bật environment HDRI cho reflection. Nút ... chọn file .hdr hoặc .exr. Bản sharp lo reflection và GI, bản blur làm background.

Export FBX
for Substance

Export selection ra FBX. Nút ... để chỉ đường dẫn Substance Painter.exe khi tool không tự tìm được.

Launch Substance
Painter

Tick sẵn thì export xong, nếu Painter chưa chạy, tool mở app và tạo project mới với file FBX vừa export.

1

Ghép cặp high – low

Bấm Pick High Poly rồi click high poly trong scene. Bấm Pick Low Poly rồi click low poly. Cuối cùng bấm Add Pair >> để đưa cặp vào list.

Muốn bỏ thì chọn dòng rồi bấm Remove Selected, hoặc Clear All để xóa hết list.

2

Set bake settings

Map Size là resolution, Format là định dạng file, Padding là phần dilation loang ra ngoài UV shell. UV Channel là map channel của low poly.

Push Amount là độ push của cage bao quanh low poly. Push thiếu thì map bị thủng, push dư thì cage bắt nhầm chi tiết bên cạnh. Chỉnh từ từ.
3

Set output folder

Bấm Browse... để chọn folder, right-click nút đó để mở folder đang set. Ô Filename Suffix là hậu tố tên file, mặc định _Normal và _Color.

4

Bake

Bake Selected chỉ chạy các dòng đang chọn trong list, Bake All Pairs chạy hết. Progress bar và dòng status dưới cùng cho biết đang bake tới file nào.

Bake xong tool tự đóng Arnold RenderView và isolate low poly vừa bake để check luôn.

5

Tool tự lo phần còn lại

Tự switch renderer, assign Standard material, thêm modifier Projection và push cage theo Push Amount, rồi nối map vào material của low poly.

Trước khi bấm: select object, vào sub-object level và chọn sẵn ít nhất một face. Bốn nút đầu lan selection ra xung quanh, mỗi nút dừng ở một ranh giới khác nhau.

Element

Lan hết element đang dính liền nhau.

Material

Lan ra nhưng dừng khi gặp Material ID khác.

Smoothgroup

Lan ra nhưng dừng ở hard edge, tức chỗ đổi smoothing group.

UV Island

Lan ra nhưng dừng ở UV seam. Ô UVchannel bên cạnh quyết định xét map channel nào.

Open Edges

Left-click để preview open edge: viewport chuyển sang clay shading, open edge sáng xanh nhưng chưa select gì. Left-click lần nữa để tắt. Right-click mới select thật các edge đó.
