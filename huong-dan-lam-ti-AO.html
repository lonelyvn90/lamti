làm tí AO

làm tí AO

Dùng để: render Dilation, setup và bake AO, chuẩn bị export sang Substance, setup bake LOD.

Thứ tự làm việc

 

  1. Chọn thư mục OutputMọi file render và bake đều lưu vào đây.
  2. Render DilationBấm là render luôn không cần chọn gì (đúng layer là được).
  3. AO Setup rồi bake AOBấm Setup trước rồi bấm bake AO sau.
  4. Setup export SubstanceBấm để move/open part rồi xuất fbx sang Substance thôi.
  5. Setup bake LODBấm để Setup và bake maps cho LOD4/5.

Các nút Setup đều Undo được (Ctrl+Z), mà làm gì làm nhớ save ra file riêng oke?

Setup export Substance + Check

Setup này dùng cho 2 mục đích :
- Gán material PBR check nhanh trong 3dsmax nếu chưa đưa vào engine.
- Xuất fbx sang Substance painter.     

  • Add PBR Material Setup xong thì bấm nút này để gán PBR material.   Nút ... thì dẫn vào folder chứa maps.
  • HDRI Reflections bật môi trường HDRI làm tí bóng 7 màu moè  . Lần đầu tick sẽ hỏi file .hdr/.exr (không có file HDR thì sẽ không phản chiếu mà phản tác dụng).   
  • Muốn xuất fbx sang Substance thì chọn object rồi bấm Export FBX for Substance. Tick Launch Substance Painter thì Substance tự mở và tạo project mới với file vừa xuất (nhưng khuyên là nên import = tay để còn chỉnh setting,tự động nhiều quá không tốt) .

làm tí Normal

làm tí Normal

Bake Normal map từ high poly sang low poly, có thể bắt nhiều cọp (cặp),dùng pick object nên không cần điều kiện gì về tên tuổi,quê quán hoặc năm sinh.     

Các bước :

  1. Bấm Pick High Poly
  2. Bấm Pick Low Poly
  3. Bấm Add Pair >>. Danh sách hiện dạng high --> low.

Lặp lại thao tác để add thêm cặp low-high khác.  

Remove Selected xoá các dòng đang chọn (Ctrl/Shift- để chọn nhiều). Clear All xoá hết.

làm tí ID

làm tí ID

Dùng chữa cháy thay thế bảng "M" của 3dsmax. Trực quan,thao tác đơn giản,đỡ tù túng như mặc định.     

Multi/Sub

  • Ở đâu có chữ thì Double-click để đổi tên,đổi ID (đặt ID).
  • Nút ▼ mở danh sách để chuyển sang Multi/Sub khác nếu đang chọn nhiều object và khác material.    
  • Dòng chữ xanh là để tìm object bị lạc trong scene,nếu chọn nhiều quá mà không biết object đang thao tác nó ở where?

  • Bấm LOD nào thì show only LOD đó.
